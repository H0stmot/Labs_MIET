# Лабораторные работы МИЭТ по архитектуре процессорных систем

Лабораторные работы показывают последовательную разработку цифровых блоков: от
полного сумматора и АЛУ до самодостаточной процессорной системы с памятью,
LSU, CSR, обработкой прерываний и аппаратным умножителем чисел с плавающей
точкой.

Итоговая версия находится в [`processor/`](processor/) — это интегрированная
сборка процессора. Исходные папки лабораторных
сохранены как история поэтапной разработки.

## Что реализовано

- 32-битный регистровый файл с нулевым регистром `x0`;
- АЛУ с арифметическими, логическими, сдвиговыми операциями и сравнениями;
- декодер подмножества RV32I;
- память инструкций и данных;
- LSU с байтовыми, полусловными и словными обращениями;
- переходы `JAL`, `JALR` и условные ветвления;
- машинные CSR `mie`, `mtvec`, `mscratch`, `mepc`, `mcause`;
- обработка исключений, внешнего IRQ и возврата `MRET`;
- инструкция `REAL_MUL` для умножения двух значений binary32;
- системный тест, исполняющий программу непосредственно на процессоре.

## Быстрый запуск

Требуются GNU Make и Icarus Verilog 11 или новее.

```bash
make test
```

Успешный тест завершается сообщением:

```text
ТЕСТ REAL_MUL ПРОЙДЕН
1.5 * 2.0 = 3.0
Результат в data_memory.ram[0] = 0x40400000
```

## Проверяемая программа

Системный тест загружает [`processor/programs/program.mem`](processor/programs/program.mem)
в память инструкций. Программа записывает `1.5f` и `2.0f` в регистры,
выполняет `REAL_MUL`, сохраняет результат в память и переходит в бесконечный
цикл. Тестбенч проверяет, что в `RAM[0]` появилось `0x40400000`, то есть `3.0f`.
