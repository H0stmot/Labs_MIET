# Архитектура процессора

## Верхний уровень

![Верхний уровень процессорной системы](images/processor_system.png)

`processor_system` связывает память инструкций, процессорное ядро, LSU и
память данных объёмом 512 байт.

## Ядро

![Архитектура процессорного ядра](images/processor_core.png)

Ядро выполняет инструкции без конвейера. Счётчик команд обновляется на фронте
тактового сигнала, а LSU останавливает ядро на время обращения к памяти.

Целочисленные операции и четыре варианта `MUL` выполняет АЛУ. Для `REAL_MUL`
рядом с АЛУ установлен отдельный комбинационный блок FM. Перед записью в
регистровый файл результат выбирается по коду операции.

## Поддерживаемые группы инструкций

| Группа | Инструкции |
|---|---|
| U-type | `LUI`, `AUIPC` |
| Переходы | `JAL`, `JALR` |
| Ветвления | `BEQ`, `BNE`, `BLT`, `BGE`, `BLTU`, `BGEU` |
| Память | `LB`, `LH`, `LW`, `LBU`, `LHU`, `SB`, `SH`, `SW` |
| ALU immediate | `ADDI`, `SLTI`, `SLTIU`, `XORI`, `ORI`, `ANDI`, `SLLI`, `SRLI`, `SRAI` |
| ALU register | `ADD`, `SUB`, `SLL`, `SLT`, `SLTU`, `XOR`, `SRL`, `SRA`, `OR`, `AND` |
| RV32M | `MUL`, `MULH`, `MULHSU`, `MULHU` |
| System | CSR read/modify/write, `ECALL`, `EBREAK`, `MRET` |
| Пользовательская | `REAL_MUL` для binary32 |

## Исключения

При исключении адрес текущей команды сохраняется в `mepc`, причина — в
`mcause`, а выполнение продолжается с адреса `mtvec`.

| Событие | `mcause` |
|---|---:|
| Недопустимая инструкция | 2 |
| `EBREAK` | 3 |
| `ECALL` из M-mode | 11 |

Обработчик тестовой программы увеличивает `mepc` на четыре и выполняет
`MRET`, поэтому процессор продолжает работу со следующей инструкции.

## Системный тест

Тестовая программа сохраняет результаты в память данных:

| Адрес слова | Проверка | Результат |
|---:|---|---:|
| 0 | `MUL`, `-7 * 3` | `FFFFFFEB` |
| 1–3 | старшие части знаковых и беззнаковых произведений | — |
| 4 | `REAL_MUL`, `1.5 * 2.0` | `40400000` |
| 6 | причина `ECALL` | `0000000B` |
| 7 | причина `EBREAK` | `00000003` |

Метки в словах 5 и 8 подтверждают, что возврат из обоих исключений выполнен.
