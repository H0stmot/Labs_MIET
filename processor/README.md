# Интегрированная процессорная система

Самодостаточная сборка учебного 32-битного процессора: RTL, программа в
машинных кодах и системный тест. Верхний уровень `rtl/processor_system.sv`
объединяет ядро, память инструкций, LSU и память данных.

## Что добавлено

- инструкции умножения RV32M `MUL`, `MULH`, `MULHSU`, `MULHU`;
- пользовательская инструкция `REAL_MUL` для умножения чисел FP32;
- синхронные исключения `ECALL` и `EBREAK`;
- запись причины исключения в `mcause` и возврат через `MRET`.

Деление и остаток из RV32M не реализованы. Процессор остаётся простым
однотактным учебным ядром без конвейера и кэша.

## Инструкция REAL_MUL

`REAL_MUL rd, rs1, rs2` воспринимает операнды как IEEE 754 binary32 и
записывает произведение в `rd`. Для неё выделено пространство `CUSTOM-0`,
поэтому стандартная кодировка `MUL` больше не переопределяется.

| Поле | Значение |
|---|---|
| `opcode` | `0001011` |
| `funct3` | `000` |
| `funct7` | `0000000` |

В процессор подключён комбинационный вычислительный тракт из проекта FM.
Для него выбран режим округления к ближайшему чётному.

## Проверка

```bash
make test
```

Top module теста — `lab_11_tb_processor_system`. Программа проверяет четыре
варианта целочисленного умножения, `REAL_MUL` на примере `1.5 * 2.0`, а также
обработку `ECALL` и `EBREAK`.

Исходные тесты некоторых лабораторных используют возможности SystemVerilog,
которые могут требовать Questa. Интеграционный тест рассчитан на Icarus
Verilog 11 или новее.
