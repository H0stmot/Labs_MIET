# Интегрированная процессорная система

Папка содержит самодостаточную сборку учебного 32-битного процессора. В неё
включены все RTL-зависимости, программа для проверки и неинтерактивный
системный тест.

## Состав

```text
processor/
├── rtl/       # синтезируемые модули и пакеты SystemVerilog
├── tb/        # системный тестбенч
├── programs/  # образы памяти инструкций
├── docs/      # описание архитектуры
└── Makefile   # воспроизводимая сборка и запуск
```

Верхний уровень — `rtl/processor_system.sv`. Он объединяет ядро, память
инструкций, память данных и LSU. Интерфейс верхнего уровня содержит тактовый
сигнал, сброс, вход внешнего прерывания и сигнал завершения обработки IRQ.

## Запуск

Из корня репозитория:

```bash
make test
```

Или непосредственно из этой папки:

```bash
make test
```

Для ручной сборки используется top module `lab_11_tb_processor_system`.

## Пользовательская инструкция REAL_MUL

`REAL_MUL rd, rs1, rs2` интерпретирует содержимое `rs1` и `rs2` как значения
binary32 и записывает произведение в `rd`.

Кодирование:

| Поле | Значение |
|---|---|
| `opcode` | `0110011` |
| `funct3` | `000` |
| `funct7` | `0000001` |

Это кодовое пространство стандартной инструкции RV32M `MUL`, но в данном
учебном процессоре оно намеренно переопределено для floating-point операции.
Процессор не заявляет поддержку расширения RV32M.

## Границы проекта

- архитектура учебная и не конвейерная;
- реализовано подмножество RV32I, а не полный профиль соответствия RISC-V;
- `REAL_MUL` поддерживает binary32 и требует дальнейшей проверки специальных
  значений и всех режимов округления;
- системный тест проверяет основной путь исполнения и интеграцию с памятью;
- исходные тестбенчи отдельных лабораторных могут требовать Questa из-за SVA
  и других возможностей, не полностью поддерживаемых Icarus Verilog.
